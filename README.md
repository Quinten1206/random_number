# 概率决策器

一个极简的 Android 离线工具：输入概率，输出 0 或 1。

## 功能

- 支持三种输入方式：小数 (`0.5`)、分数 (`1/2`)、百分比 (`50%`)
- 点击按钮随机生成 0 或 1，结果严格按照输入概率分布
- 可重复点击，输入框不清空
- 输入非法时自动提示
- 无需网络权限，无广告，不收集任何数据

## 技术栈

- **语言**：Kotlin
- **构建**：Gradle + Android Gradle Plugin
- **UI**：传统 XML 布局
- **最低支持**：Android 7.0 (API 24)
